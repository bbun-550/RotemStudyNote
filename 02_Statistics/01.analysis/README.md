# 📁 01.analysis — 기초 통계 & 가설검정 (Statistical Inference)

**통계 분석의 출발점**으로,  
데이터의 특성을 요약하고 가설을 검정하는 전통적인 통계 기법들을 다룹니다.

## 주요 내용
- 기술통계 (빈도, 평균, 분산, 표준편차)
- 카이제곱 검정 (χ² test)
    - 적합도 검정
    - 독립성 검정 (one-way / two-way)
- t-test
    - 단일표본 / 독립표본 / 대응표본 t-test
- 비율 검정 (proportion test)
- 분산분석 (ANOVA)
    - 일원분산분석
    - 이원분산분석

📌 *“이 데이터의 차이가 통계적으로 의미 있는가?”* 를 판단
