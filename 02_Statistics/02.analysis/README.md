# 📁 02.analysis — 상관분석 & 회귀분석 (Correlation & Regression)

**변수 간 관계를 수식으로 모델링**하는 단계로,  
통계 기반 예측 모델의 핵심 이론을 다룹니다.

## 주요 내용
- 상관분석
  - Pearson 상관계수
  - 상관계수 해석 및 시각화
- 선형회귀 (Linear Regression)
  - 단순 회귀 / 다중 회귀
  - 회귀계수 해석
  - 결정계수(R²)
- 회귀 진단
  - 잔차 분석
  - 비선형 회귀
- 규제(Regularization)
  - Ridge / Lasso (Penalty 개념)
- 실제 데이터셋 실습
  - iris, mtcars, boston, carseats 등
- 회귀 결과를 웹(Django)로 시각화하는 실습 포함

📌 *“입력 X가 바뀌면 출력 Y는 어떻게 변하는가?”* 를 설명
