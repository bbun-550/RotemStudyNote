# 📁 03.analysis — 지도학습 기반 머신러닝 모델

통계적 회귀 분석을 확장하여  
**분류·예측을 위한 머신러닝 모델**을 학습하는 단계입니다.

## 주요 내용
- 분류 모델
  - 로지스틱 회귀
  - KNN
  - Naive Bayes
  - SVM
- 트리 기반 모델
  - Decision Tree
  - Random Forest
  - Ensemble 기법
  - Boosting
- 신경망 기초
  - ANN / MLP
- 차원 축소
  - PCA (주성분 분석)
- 모델 평가
  - ROC Curve
  - Overfitting / Underfitting

📌 *“통계 → 머신러닝으로 넘어가는 경계 구간”* 핵심 파트
