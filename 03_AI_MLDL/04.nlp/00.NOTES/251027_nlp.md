# 📘 NLP 기본 이론 정리 — Tokenization → Vectorization → Embedding

자연어 처리(NLP) 실습(nlp01, nlp02, nlp03)을 관통하는 핵심 이론 정리 문서
(Word2Vec, 형태소 분석, 벡터 공간 의미 표현 중심)

## 1. 자연어 처리(NLP)의 출발점

Natural Language Processing (NLP)
사람이 사용하는 자연어를 컴퓨터가 이해·처리할 수 있도록 변환하는 기술

한국어의 특징:
- 교착어: 조사, 어미가 결합되어 의미 변화가 큼
- 공백 기준 분리가 불완전 → 형태소 분석 필수

---

## 2. Corpus와 Tokenization

### 🔹 Corpus (말뭉치)
- 분석 대상이 되는 텍스트 데이터 전체 집합
- 예: 뉴스 기사 전체, 리뷰 문장 모음, 사내 문서 집합


### 🔹 Token (토큰)
문장에서 분리된 의미 분석의 최소 단위

**토큰화 단위 종류**


| 구분   | 설명        | 예시             |
| ---- | --------- | -------------- |
| 단어   | 공백 기준 분리  | I / Love / NLP |
| 형태소  | 의미 최소 단위  | 먹 / 었 / 다      |
| 서브워드 | 통계적 하위 단위 | play / ing     |
| 문자   | 글자 단위     | A / I          |


**목적**
- 텍스트 → 기계가 처리 가능한 단위로 분해
- 후속 단계(벡터화, 임베딩)의 입력 준비

💡 비유: 레고 블록으로 만들기 전에 블록을 분해하는 과정


### 🔹 Tokenization (토큰화)

문장을 토큰 단위로 나누는 전처리 단계
- 구두점 처리
- 대소문자 정규화
- 불용어(Stopword) 제거
- 어간/표제어 추출

nlp03 실습
- `konlpy.Okt` 사용
- 명사(Noun), 동사(Verb) 중심 추출
- `stem=True`로 동사 원형화

## 3. Vocabulary (어휘집)
- 토큰화 후 얻은 고유 단어 집합
- Word2Vec, BoW, TF-IDF의 기준 공간

예:
\
{자연어, 처리, 공부, 회사, 주식}


---

## 4. 단순 벡터화 (Frequency 기반)

### 🔹 Bag of Words (BoW)
- 단어 등장 빈도만 사용
- 단어 순서, 문맥 무시

한계
- 고차원 & 희소 벡터
- 의미 손실
- 문장 순서 동일 취급

---

### 🔹 TF-IDF
- TF(빈도) × IDF(희소성)
- BoW 개선 버전

장점
- 문서별 핵심 단어 강조

한계
- 여전히 문맥/의미 반영 부족
- 희소 벡터 구조

---

## 5. Embedding (임베딩) — 핵심 전환점

### 🔹 Embedding 개념
- 단어/문장을 저차원 밀집 벡터로 변환
- 의미·문맥 유사성 → 벡터 거리/방향으로 표현

특징
- Dense Vector
- 저차원 (수십~수백)
- 의미 기반 표현
- 학습 기반

---

## 6. 정적 단어 임베딩 (Static Embedding)

### 🔹 Word2Vec (nlp02, nlp03 핵심)

학습 방식


| 방식        | 설명            |
| --------- | ------------- |
| CBOW      | 주변 단어 → 중심 단어 |
| Skip-Gram | 중심 단어 → 주변 단어 |


실습 설정

```python
Word2Vec(
  vector_size=100,
  window=10,
  sg=1  # Skip-Gram
)
```

장점
- 의미 유사성 학습
- 코사인 유사도로 단어 관계 파악 가능

한계
- 단어 하나당 하나의 벡터
- 다의어 처리 불가

예:
- 배(boat) / 배(pear)
- 사과(apology) / 사과(apple)

## 7. 코사인 유사도 (Cosine Similarity)

임베딩 공간에서 의미 유사도 측정의 핵심 지표
- 값 범위: -1 ~ 1
- 방향이 비슷할수록 유사

nlp02 / nlp03
- model.wv.similarity()
- 각도 → 의미적 거리 해석

👉 [참고 - 코사인 유사도 추가 학습](00.NOTES/cosine_similarity.md)￼

## 8. 벡터 연산 기반 의미 추론

Word2Vec의 대표적 특징

```yaml
king - man + woman ≈ queen
```

nlp03 실습 예
- 주식시장 + 한국 - 한국 → 의미 보존 테스트

벡터 공간에서 “의미 연산”이 가능함을 체험

---

## 9. 임베딩 시각화 & 군집화

### 🔹 PCA (차원 축소)
- 고차원 임베딩 → 2D 시각화
- 의미적으로 가까운 단어 군집 확인

### 🔹 KMeans / Hierarchical Clustering
- 단어 의미 군집화
- Dendrogram으로 계층 구조 확인
