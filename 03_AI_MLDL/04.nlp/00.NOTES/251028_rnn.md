# **📘 RNN & LSTM 구조 이해와 시계열 학습 이론 정리**


## 1. 시계열 데이터와 신경망 입력 구조

RNN 계열 모델은 **순서가 있는 데이터(sequence)** 를 처리하기 위해 설계된 신경망이다.

일반적인 Dense 네트워크와 달리, 입력 데이터는 반드시 **3차원 텐서** 형태를 가진다.

```
(batch_size, timesteps, input_dim)
```

|**축**|**의미**|
|---|---|
|batch_size|한 번에 학습/추론하는 시퀀스 묶음 개수|
|timesteps|시퀀스 길이 (시간 축)|
|input_dim|각 시점에서의 입력 벡터 크기|

rnn01에서는 이 구조를 **모델 summary와 출력 텐서 변화**를 통해 직접 확인했다.

## 2. 순환 신경망(RNN)의 기본 동작 원리
RNN은 이전 시점의 은닉 상태(hidden state)를 다음 시점으로 전달한다.

```
hₜ = tanh(Wₓxₜ + Wₕhₜ₋₁ + b)
```
>**tanh** : 하이퍼볼릭 탄젠트(Hyperbolic Tangent)
>- 실수 값을 입력받아 -1과 1 사이의 값으로 압축하는 S자 곡선 형태의 수학 함수이
>- 특히 딥러닝에서 신경망의 활성화 함수로 널리 사용
>- 입력 데이터를 중심화(zero-centered)하고 비선형성을 부여하는 역할
>- $\text{sigmoid}$ 함수와 유사하지만 출력이 양수뿐 아니라 **음수도 포함하여 더 효율적**

- **현재 입력(xₜ)** 과 **이전 상태(hₜ₋₁)** 를 함께 사용
- 시점 간 정보가 연결되며 시계열 패턴 학습 가능
- 단점: **장기 의존성(Long-Term Dependency) 문제** (아래 "LSTM 등장배경"애서 설명)
    - 시퀀스가 길어질수록 초기 정보가 사라짐 (기울기 소실)


---

## 3. RNN 출력 구조: many-to-one vs many-to-many
rnn01에서 return_sequences 옵션에 따라 출력 구조가 달라지는 것을 확인했다.
### ✔ many-to-one (기본값)

```
model = Sequential()
model.add(Input(batch_size=8, shape=(2, 10)))    # 입력 텐서 = (8, 2, 10)
model.add(SimpleRNN(units=3))
model.summary()
```

- 출력 형태: (batch_size, units) ➜ (8, 3)
- 마지막 시점의 정보만 사용
- 예: 시계열 예측, 문장 분류
### ✔ many-to-many

```
model.add(SimpleRNN(units=3, return_sequences=True))
```

- 출력 형태: (batch_size, timesteps, units)
- 모든 시점의 출력을 반환
- 예: 단어 생성, 시퀀스 라벨링

이 개념은 이후 **문자 생성 / 단어 생성 RNN** 실습의 기반이 된다.

## 4. LSTM(Long Short-Term Memory)의 등장 배경

rnn02에서 RNN 대신 **LSTM을 사용한 이유**는 명확하다.

> RNN은 짧은 패턴은 잘 학습하지만,
> **시간 간격이 긴 정보는 유지하지 못한다.**

### ‼️ 장기 의존성(Long-Term Dependency) 개념
#### 장기 의존성이란?

> 시퀀스가 길어질수록,
> **초기 입력 정보가 뒤쪽 출력에 거의 영향을 주지 못하는 현상**

예시 (자연어):
> _“나는_ **_어제 비가 와서 우산을 썼다_**_고 말했지만,_
> _지금 그는 왜 우산을 들고 있을까?”_

- “우산”의 이유는 **문장 초반 정보**
- 하지만 RNN은 뒤로 갈수록 이 정보 전달에 실패
    
#### RNN에서 장기 의존성이 발생하는 이유

RNN의 기본 수식:
$$h_t = \tanh(W_x x_t + W_h h_{t-1} + b)$$

- 은닉 상태 $h_t$ 는 이전 상태 $h_{t-1}$에 **반복적으로 곱셈**
- 역전파 시:
$$\frac{\partial L}{\partial h_{t-k}} = \prod_{i=1}^{k} W_h^\top \cdot \tanh'( \cdot )$$
**문제점**
- $|W_h| < 1$ → **기울기 소실 (Vanishing Gradient)**
- $|W_h| > 1$ → **기울기 폭주 (Exploding Gradient)**

👉 결과적으로 **초기 시점 정보는 학습 과정에서 사라짐**

#### LSTM이 장기 의존성을 완화한 방식 (요약)

LSTM은 다음을 도입했다.
- **Cell State** $C_t $: 거의 선형으로 전달되는 메모리 통로
- **Gate 구조** : 정보 선택적 유지

하지만,
> **LSTM도 “출력 시점마다 입력 전체를 다시 보는 구조”는 아님** 
> → 출력 시점마다 보는 구조는 attention


LSTM은 **셀 상태(Cell State)** 와 **게이트 구조**를 도입

## 5. LSTM 내부 구조 핵심

LSTM은 다음 4개의 게이트로 구성된다.

|**게이트**|**역할**|
|---|---|
|Forget Gate|과거 정보 중 버릴 것 결정|
|Input Gate|새로 저장할 정보 선택|
|Cell Update|셀 상태 업데이트|
|Output Gate|외부로 출력할 정보 결정|

이 구조 덕분에:
- 중요한 정보는 오래 유지
- 불필요한 정보는 점진적으로 제거
- 장기 시계열 학습 가능

rnn01에서는 **파라미터 수 계산식**으로 이 구조를 수치적으로 확인했다.

```yaml
LSTM 파라미터 수 =
4 × (input_dim + units + 1) × units
```
→ 게이트 수(4개)만큼 파라미터가 증가

## 6. RNN vs LSTM 구조 비교 (한 장 요약)

|**항목**|**SimpleRNN**|**LSTM**|
|---|---|---|
|은닉 상태|단일 상태|셀 상태 + 은닉 상태|
|장기 의존성|❌ 취약|✔ 강함|
|게이트 구조|없음|Forget / Input / Output|
|파라미터 수|적음|많음|
|학습 안정성|낮음|높음|
|사용 예|짧은 시계열|대부분의 시계열 문제|

## 7. LSTM 기반 시계열 예측 구조 (rnn02)
rnn02에서는 **숫자 시퀀스를 입력으로 받아 다음 값을 예측**하는 문제를 다뤘다.

### ✔ 입력 데이터 구성
- 입력: 길이 3 시퀀스
- 출력: 다음 시점의 값
- 입력 변환:

```
(samples, timesteps, features)
→ (8, 3, 1)
```

### ✔ 모델 구조

```python
model = Sequential()
model.add(Input(shape=(3,1)))
model.add(LSTM(10, activation='relu'))
model.add(Dense(1, activation='linear'))
```

- 회귀 문제 → 출력층 활성화 함수는 `linear`
- 손실 함수: `mse`
- 최적화: `adam`
- LSTM activation 활성화함수로 대체로 tanh를 사용한다.
    - relu : 음수 표현이 어렵고, 값이 커지면 안정성이 떨어질 수 있다.

## 8. 왜 RNN/LSTM은 Dense와 다른가?

**Dense 네트워크**:
- 입력 간 **순서 정보 없음**
- 독립적인 feature 처리
    
**RNN/LSTM**:
- 입력 간 **시간적 관계 학습**
- 이전 정보가 현재 출력에 직접 영향
    
이 차이 때문에:
- 시계열
- 자연어
- 음성
- 로그 데이터
와 같은 문제에서 RNN 계열이 필수적으로 사용된다.
