# **📘 RNN & LSTM 구조 이해와 시계열 학습 이론 정리**


## 1. 시계열 데이터와 신경망 입력 구조

RNN 계열 모델은 **순서가 있는 데이터(sequence)** 를 처리하기 위해 설계된 신경망이다.

일반적인 Dense 네트워크와 달리, 입력 데이터는 반드시 **3차원 텐서** 형태를 가진다.

```
(batch_size, timesteps, input_dim)
```

|**축**|**의미**|
|---|---|
|batch_size|한 번에 학습/추론하는 시퀀스 묶음 개수|
|timesteps|시퀀스 길이 (시간 축)|
|input_dim|각 시점에서의 입력 벡터 크기|

rnn01에서는 이 구조를 **모델 summary와 출력 텐서 변화**를 통해 직접 확인했다.

---

## 2. 순환 신경망(RNN)의 기본 동작 원리
RNN은 이전 시점의 은닉 상태(hidden state)를 다음 시점으로 전달한다.

```
hₜ = tanh(Wₓxₜ + Wₕhₜ₋₁ + b)
```

- **현재 입력(xₜ)** 과 **이전 상태(hₜ₋₁)** 를 함께 사용
- 시점 간 정보가 연결되며 시계열 패턴 학습 가능
- 단점: **장기 의존성(Long-Term Dependency) 문제**
    - 시퀀스가 길어질수록 초기 정보가 사라짐 (기울기 소실)

## 3. RNN 출력 구조: many-to-one vs many-to-many
rnn01에서 return_sequences 옵션에 따라 출력 구조가 달라지는 것을 확인했다.
### ✔ many-to-one (기본값)

```
SimpleRNN(units=3)
```

- 출력 형태: (batch_size, units)
- 마지막 시점의 정보만 사용
- 예: 시계열 예측, 문장 분류
### ✔ many-to-many

```
SimpleRNN(units=3, return_sequences=True)
```

- 출력 형태: (batch_size, timesteps, units)
- 모든 시점의 출력을 반환
- 예: 단어 생성, 시퀀스 라벨링

이 개념은 이후 **문자 생성 / 단어 생성 RNN** 실습의 기반이 된다.

## 4. LSTM(Long Short-Term Memory)의 등장 배경

rnn02에서 RNN 대신 **LSTM을 사용한 이유**는 명확하다.

> RNN은 짧은 패턴은 잘 학습하지만,
> **시간 간격이 긴 정보는 유지하지 못한다.**
  

이를 해결하기 위해 LSTM은 **셀 상태(Cell State)** 와 **게이트 구조**를 도입한다.

---

## 5. LSTM 내부 구조 핵심

LSTM은 다음 4개의 게이트로 구성된다.

|**게이트**|**역할**|
|---|---|
|Forget Gate|과거 정보 중 버릴 것 결정|
|Input Gate|새로 저장할 정보 선택|
|Cell Update|셀 상태 업데이트|
|Output Gate|외부로 출력할 정보 결정|

이 구조 덕분에:
- 중요한 정보는 오래 유지
- 불필요한 정보는 점진적으로 제거
- 장기 시계열 학습 가능

rnn01에서는 **파라미터 수 계산식**으로 이 구조를 수치적으로 확인했다.
```
LSTM 파라미터 수 =
4 × (input_dim + units + 1) × units
```
→ 게이트 수(4개)만큼 파라미터가 증가

---

## 6. RNN vs LSTM 구조 비교 (한 장 요약)

|**항목**|**SimpleRNN**|**LSTM**|
|---|---|---|
|은닉 상태|단일 상태|셀 상태 + 은닉 상태|
|장기 의존성|❌ 취약|✔ 강함|
|게이트 구조|없음|Forget / Input / Output|
|파라미터 수|적음|많음|
|학습 안정성|낮음|높음|
|사용 예|짧은 시계열|대부분의 시계열 문제|

## 7. LSTM 기반 시계열 예측 구조 (rnn02)
rnn02에서는 **숫자 시퀀스를 입력으로 받아 다음 값을 예측**하는 문제를 다뤘다.

### ✔ 입력 데이터 구성
- 입력: 길이 3 시퀀스
- 출력: 다음 시점의 값
- 입력 변환:

```
(samples, timesteps, features)
→ (8, 3, 1)
```

### ✔ 모델 구조

```python
LSTM(units=10)
Dense(1, activation='linear')
```

- 회귀 문제 → 출력층 활성화 함수는 `linear`
- 손실 함수: `mse`
- 최적화: `adam`

## **🔹 8. 왜 RNN/LSTM은 Dense와 다른가?**

**Dense 네트워크**:
- 입력 간 **순서 정보 없음**
- 독립적인 feature 처리
    
**RNN/LSTM**:
- 입력 간 **시간적 관계 학습**
- 이전 정보가 현재 출력에 직접 영향
    
이 차이 때문에:
- 시계열
- 자연어
- 음성
- 로그 데이터
와 같은 문제에서 RNN 계열이 필수적으로 사용된다.
