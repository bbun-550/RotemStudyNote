# 📘 Character-level Language Model & Text Generation 이론 정리

**문자 단위(Character-level) 언어 모델**과
이를 활용한 **텍스트 생성(Text Generation)** 실습에서 새롭게 등장하는 이론 개념을 정리한다.

---

## 1. Character-level Language Model이란?

**Character-level Language Model**은
단어(word)가 아니라 **문자(character)** 를 토큰 단위로 사용하는 언어 모델이다.

- 입력 단위: 문자 (a, b, 가, . 등)    
- 출력 단위: 다음에 등장할 **문자 1개**    
- 모델 목표:    
> 이전 문자 시퀀스를 보고, 다음 문자가 나올 확률 분포를 예측

## 2. Character-level Tokenization의 특징
### **2-1. 문자 단위 토큰화**

- 텍스트 전체에서 **고유 문자 집합(Charset)** 생성    
- 각 문자를 정수 인덱스로 매핑    

```yaml
"hello" → ['h','e','l','l','o']
```

**특징**

- Vocabulary 크기가 매우 작음    
- OOV(Out-of-Vocabulary) 문제 없음    
- 철자·형태 패턴 학습에 강함    
- 의미 단위 이해는 약함

👉 토큰화 기본 개념
\

---

### 2-2. 단어 단위 vs 문자 단위 비교

|**구분**|**단어 단위**|**문자 단위**|
|---|---|---|
|Vocabulary 크기|큼 (수천~수만)|매우 작음|
|OOV 문제|존재|없음|
|의미 이해|강함|약함|
|철자/형태|약함|강함|
|생성 안정성|비교적 안정|불안정|

## 3. Character-level 시퀀스 데이터 구성

### 3-1. 슬라이딩 윈도우 방식

고정 길이 seq_length를 기준으로 입력/출력 생성

```yaml
입력:  "hel"
출력:  "l"

입력:  "ell"
출력:  "o"
```

- 입력(X): 이전 N개의 문자    
- 정답(y): 바로 다음 문자 1개    

---

### 3-2. 데이터 텐서 형태

문자 단위 모델의 입력 형태는 보통 다음과 같다.

```yaml
(samples, timesteps, vocab_size)
```

- samples: 학습 샘플 수    
- timesteps: 입력 문자 개수    
- vocab_size: 전체 문자 집합 크기 (One-Hot 차원)

## 4. Character-level One-Hot Encoding

문자 인덱스를 **One-Hot Vector**로 변환하여 모델에 입력한다.

- 문자`'a' → [0,0,1,0,...]`    
- 장점: 단순, 직관적    
- 단점: vocab_size가 커질수록 비효율적

## 5. Character-level LSTM 모델 구조

### 5-1. 기본 구조

```yaml
Input → LSTM → Dense(Softmax)
```

- LSTM: 이전 문자들의 패턴 기억    
- Softmax: 다음 문자의 확률 분포 출력    
- 출력 차원 = vocab_size    

---

### 5-2. 모델의 역할

- 문법을 “이해”하는 것이 아니라    
- **문자 등장 확률 분포를 학습**함    
- 학습 데이터의 스타일·패턴을 모방    

---

## 6. Auto-regressive Text Generation

### 6-1. Auto-regressive 구조란?

모델의 **출력 결과를 다시 입력으로 사용하는 방식**
```yaml
seed → 예측 → 입력에 추가 → 다시 예측 → 반복
```

- 사람이 문장을 이어 쓰는 방식과 유사    
- 언어 모델의 핵심 생성 방식

## 7. Sampling Strategy (샘플링 전략)
### 7-1. Argmax 방식의 한계

- 항상 확률이 가장 높은 문자 선택    
- 결과가 반복적이고 단조로워짐    

---

### 7-2. Temperature Sampling

Softmax 확률 분포의 **분산 조절**

```yaml
temperature ↓  → 보수적, 안정적, 반복적
temperature ↑  → 다양성 증가, 노이즈 증가
```

- 낮을수록 확률이 뾰족    
- 높을수록 다양한 문자 선택 가능    

---

### 7-3. Top-k Sampling

- 확률 상위 k개 문자만 후보로 남김    
- 극단적으로 낮은 확률 문자 제거    
- 생성 품질 안정화    

---

## 8. Character-level 모델의 한계와 의의

### 한계

- 의미 단위 이해 부족    
- 긴 문장 생성 시 논리 붕괴    
- 장기 의존성에 취약    

### 의의

- 언어 모델의 **가장 원초적인 형태**    
- RNN → Attention → Transformer로 발전하는 흐름의 출발점    
- “언어 생성은 확률 문제”라는 직관 제공
