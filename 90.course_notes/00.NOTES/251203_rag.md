# 📘 RAG & 멀티모달 기본 이론 정리

Retrieval-Augmented Generation + 이미지 기반 멀티모달 생성 개념 문서

## 1. LLM의 한계를 해결하는 RAG

대규모 언어모델은 강력하지만 다음과 같은 한계를 가진다:

- 모델이 기억할 수 있는 컨텍스트 길이(토큰 한도)가 제한됨
- GPT-4 기준: 128k
- Gemini 기준: 최대 백만 단위 토큰(수백 개 문서 분량)도 가능
- 사전학습 데이터 이후의 **최신 정보는 모름**
- 특정 전문 지식 분야에서는 **할루시네이션(근거 없는 답변)** 발생 가능

>💡 **RAG**는 LLM의 이러한 한계를 보완하는 대표 기술

---

## 🚀 2. RAG 작동 흐름 (Retrieval → Generation)

### ✅ 1단계: 정보 검색 Retrieval

LLM이 가진 내부 지식 대신,
외부 문서·DB·PDF·웹 정보 등에서 필요한 정보를 찾는 단계.
- 사용자가 입력한 질문을 벡터화하여 쿼리 벡터(query vector) 생성
- VectorDB(Chroma, FAISS, Pinecone) 등에서 유사한 문서 벡터 검색
- ElasticSearch 기반 BM25, Hybrid Search 등도 사용 가능

<br>

**📌 Retrieval의 핵심 아이디어**

텍스트를 임베딩 벡터(숫자 배열)로 변환 → 가장 가까운 벡터를 찾아 반환
(= 의미 기반 검색 Semantic Search)

<br>

**🔎 정보검색 알고리즘 예**

- **ElasticSearch**

	- 키워드 기반 검색 중심
	- 역색인(Inverted Index) 구조
	- 법률/웹 서비스 검색에 강함

- **Pinecone / ChromaDB**

	- 벡터 기반 의미 검색
	- LLM 기반 RAG에 최적화

### ✅ 2단계: 생성 Generation

검색된 문서를 LLM의 Context로 삽입하여 응답 생성.
- LLM은 검색된 문서 내용을 참고하기 때문에 더 정확하고 신뢰도 높은 대답 생성 가능
- RAG의 품질은 “검색된 문서의 품질”에 크게 의존

---

## 🎯 3. RAG 특징 요약

- 특징 설명 정보 신뢰도 증가. 
- 외부 최신 문서 기반으로 정확한 응답.
- 작은 모델로도 고성능	
- Retrieval을 사용해 LLM이 몰라도 되는 지식 제거
- 유연성 : 데이터만 교체해도 바로 최신 정보 반영
- 확장성 : 문서 수가 증가해도 검색 기반으로 확장 용이

---

## 💡 4. RAG의 대표 활용 사례

- 고객센터 Q&A 자동 응답
- 기업 내부 문서 검색봇
- 법률/의료 문서 기반 전문 보조 AI
- 뉴스 기반 실시간 질의응답
- 문서 요약 + 정보 추출 시스템
- 사용자 취향 기반 추천 시스템

## 5. Multimodal 모델 개념 정리

**🔹 (1) *멀티모달(Multimodal) 모델*이란?**

- 텍스트, 이미지, 오디오, 비디오 등 여러 입력 형태를 동시에 처리
- Gemini, GPT-4o, Claude 3.5 모두 멀티모달 LLM
- 이미지 입력 시 모델은 다음과 같은 reasoning을 수행:
- 객체 감지
- 장면 이해
- 텍스트 변환
- 요약 / 분석 / 창작 등

<br>

**🔹 (2) 이미지 설명 생성(Image Captioning)의 역할**

RAG에서 특히 중요한 이유:

	1.	이미지를 텍스트로 변환해야 임베딩이 가능함
	2.	텍스트 벡터로 변환해야 검색 가능함
	3.	PDF 내 이미지, 스캔 문서 등 처리에 필수

rag01.ipynb은 이미지 기반 RAG의 기초 단계 

<br>


**🔹 (3) 시스템 프롬프트의 역할**

LLM에게 “어떤 역할로 응답하라”를 지정하는 가이드라인.

- 일반 설명 전문가
- 시인
- 엔지니어
- 분석가
- 문서 요약가

이렇게 역할 지정에 따라 출력 형태가 달라진다.

즉, multimodal + prompt engineering의 핵심 개념을 배우는 부분.

<br>


**🔹 (4) stream=True vs stream=False**

옵션 설명 : 
- `stream=False` : 전체 답변을 한 번에 출력
- `stream=True` : 부분(chunks) 단위로 실시간 출력

stream 출력은
- 대용량 응답 처리
- 실시간 UI(ChatGPT처럼) 구성
- rag11_async 실습에서 본격적으로 등장

## 🧠 8. Sentence Transformers, Pretrained Models

이미지를 텍스트로 변환한 후에는 **텍스트 임베딩**이 필요하다.

[SentencTransformer Model](https://www.sbert.net/docs/sentence_transformer/pretrained_models.html)

대표 모델:

- `all-MiniLM-L6-v2`: 빠르고 가벼움
- `multi-qa-mpnet-base-dot-v1`: 검색 성능 우수
- `clip-ViT` 시리즈: 이미지-텍스트 매칭에 강함
